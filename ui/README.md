# ProcureCompare UI

This is the frontend UI for the ProcureCompare application, built with Next.js, React, and Tailwind CSS.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- Modern, responsive UI
- Navigation sidebar with:
  - Dashboard
  - Projects
  - Connections
  - Quick actions for adding and comparing quotes
- User profile section
- Built with TypeScript for type safety
- Styled with Tailwind CSS for consistent design

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Heroicons
